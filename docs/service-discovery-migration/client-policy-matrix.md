## Scope

This matrix classifies every RestClient consumer listed for Wave 0.

Category meanings:

- direct-discovery: internal service call using `@LoadBalanced RestClient.Builder` targeting `http://{serviceId}` via Eureka. Caller injects `X-Authorities` and `X-User` headers directly. This is the default for all internal runtime calls.
- gateway-exception: internal call that must remain routed through `http://api-gateway` as a documented exception (currently: pos-mcp-server facade tools that relay end-user bearer tokens requiring gateway JWT validation).
- direct-exception: internal call intentionally retained as a plain (non-LoadBalanced) direct call, bypassing both gateway and Eureka discovery.
- startup-infra: startup registration call that should not depend on Eureka readiness and should use Docker DNS hostnames.
- external: third-party API call.
- tax-exemption: call to pos-tax, which is internal-only and excluded from gateway/Eureka migration by ADR-0021.
