ZERO-CONFIGURATION INTEGRATION:
When a module adds pos-events as dependency:
1. ClassLoader discovers META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
2. Spring Bootstrap loads PosEventsApplication auto-configuration
3. Auto-config injects ApplicationEventPublisher
4. Auto-config creates EmitEventAspect bean (intercepts @EmitEvent)
5. Auto-config creates EmitEventProxyFactory bean (optional manual emission)
6. Aspect automatically intercepts all @EmitEvent annotated methods
7. Events published via Spring ApplicationEventPublisher (async)
8. Consumers can listen via @EventListener annotation
