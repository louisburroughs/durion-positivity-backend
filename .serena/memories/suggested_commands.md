Use ./mvnw for builds and tests. Common commands: ./mvnw -DskipTests=false clean test (all tests), ./mvnw -pl pos-order -am test (module tests), ./mvnw -pl pos-api-gateway -am clean package (build gateway + deps), ./mvnw -pl pos-order -am clean package (single service build), cd <module> && ./mvnw spring-boot:run (run service). Standard Linux utilities are available including git, ls, cd, grep/find, and gh.
